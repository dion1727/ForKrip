# Berkontribusi pada Kriptofull

Terima kasih atas ketertarikan untuk berkontribusi. Pastikan perubahan tidak merusak kompatibilitas ciphertext lama dan tidak memasukkan data pribadi, dokumen rahasia, atau password asli dalam test fixture.

1. Buat branch untuk perubahan.
2. Tambahkan tes otomatis untuk bug atau fitur baru.
3. Jalankan `python -m unittest discover -s tests -v`.
4. Jelaskan perubahan antarmuka/API dan format ciphertext dalam pull request.

Gunakan nama variabel yang jelas, periksa pesan error, dan buat contoh dari data sintetis saja.
